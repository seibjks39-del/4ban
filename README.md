# 4班人能飞 — 照片墙网站

## 功能
- 简约白色响应式布局，适配安卓手机。
- 左上角网站标题，右上角实时显示北京时间（每秒刷新）。
- 固定 20 个照片区域，每排 4 个。
- 管理面板可选择区域、上传/替换图片、清空图片。
- 图片保存到当前浏览器的 localStorage；每张图片最大 3 MB。

## 本地使用
直接打开 `index.html` 即可预览。部分手机浏览器对本地文件的存储行为可能有限，建议部署到 HTTPS 静态网站托管服务后使用。

## 免费部署到 GitHub Pages
1. 在 GitHub 注册或登录账号。
2. 新建一个公开仓库，例如 `class-gallery`。
3. 上传本项目中的 `index.html`、`style.css`、`app.js`（README 可选）到仓库根目录。
4. 进入仓库 `Settings` → `Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. Branch 选 `main`，目录选 `/(root)`，点击 `Save`。
7. 等待部署完成，页面会给出类似 `https://你的用户名.github.io/class-gallery/` 的网址。

## 重要说明
- 这是无需后端的静态网站原型。照片只保存在当前设备、当前浏览器中，不会自动同步给其他访问者。
- “进入管理”目前是前端管理面板，不是带密码的安全后台。任何访问网站的人都可能操作自己的本地照片数据。
- 如果要让所有访客看到同一批照片、多人登录管理或设置管理员密码，需要增加云端数据库、身份验证和上传存储。不要把管理员密码或云服务密钥直接写进前端代码。
- 真实支付功能不在本项目中。
